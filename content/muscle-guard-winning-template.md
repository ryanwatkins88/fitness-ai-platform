# Muscle Guard — Winning Post Template (Reverse-Engineered)

This template is built from a real post that generated inbound interest — not a hypothetical. Reuse this skeleton for new posts rather than the plainer Category I captions in the main hooks-and-captions file; this structure is proven to convert better.

## The skeleton

1. **Credit them first** — "You did the hard part." Never open by pointing out a flaw.
2. **On-screen hook, ends with a caption-redirect** — "Ever notice how some people [X] and [unexpected outcome]? Check the caption for why." This forces a caption-open instead of a scroll-past.
3. **Symptom-specific question** — name the exact thing they're noticing about their body.
4. **The reveal** — "Here's what many don't always realize: [muscle vs. fat truth]."
5. **The stakes, using a callback word from the hook** — closes the loop instead of introducing a new idea.
6. **Compact credibility** — NASM cert + 15+ years + PTA graduate + one line of relevant specific experience. Never longer than 2 sentences.
7. **The offer** — "So I built Muscle Guard, a 6-week protocol that [promise]."
8. **Scarcity** — "I'm taking 5 people through it as a beta. Only 5."
9. **Reasoned guarantee** — state the deposit/refund mechanic *and* explain why it's structured that way (filters for people who'll show up). The reasoning is what makes it trustworthy, not just the mechanic alone.
10. **Plain-question CTA** — "Who wants in?" — not a keyword command, reads like a real conversation.

**Note on the offer mechanic:** this real post describes it as a **small deposit** (not the full program cost) that's fully refunded on completion, plus explicit scarcity (**only 5 spots**) — both are refinements on what's in the other content files. ## Usage notes

- Post these in place of, not in addition to, the plainer Category I captions in the main hooks-and-captions file — this structure is proven, that one wasn't tested against real inbound interest.
- Vary the hook's exact wording each time so five posts in a row don't read as a template — the specific symptom is what should change; keep the underlying skeleton.
- Since "only 5" is a real, finite number: once those 5 spots are filled, either stop running these or update the copy — running "only 5" scarcity after the beta is full undermines trust the moment someone points it out.
